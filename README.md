# TabletopParty（桌游派对）

面向 HarmonyOS 手机、平板和二合一设备的近场桌游合集。工程由独立模板创建，桌面名称为“桌游派对”，Bundle Name 为 `com.example.tabletopparty`，目标与兼容 SDK 均为 `6.0.2(22)`，不是元服务（`installationFree=false`）。

## 当前可运行内容

- 12 款主游戏：谁是卧底、斗地主、中国象棋、军棋、狼人杀、彩牌对决、五子棋、黑白棋、飞行棋、四川麻将、掼蛋、你画我猜。
- 3 款派对工具：你演我猜、数字炸弹、真心话大冒险。
- 五子棋、黑白棋、中国象棋提供简单与普通 AI；AI 在 UI 线程外没有额外长任务，规则测试要求单步小于 1 秒。
- 大厅支持分类、搜索、AI 标识、手机单栏及大屏双栏；包含详情、建房、入局、对局、内容库、战绩与设置页面。
- 内置原创内容达到：卧底 330 组、画猜 360 条、演猜 320 条、真心话 180 条、大冒险 180 条、狼人杀 7 套人数配置。
- 支持 `ContentPackV1` 文本导入，执行版本、游戏类型、大小、字段、重复项与危险执行文本校验。

## 架构

- `GamePlugin` + `GameRegistry`：15 个玩法均通过注册表创建，大厅不硬编码玩法分支。
- `RoomEngine`：房主裁决、版本号、席位、AI、私密玩家视图和简要战绩。
- `RoomEnvelopeV3`：`TP3` 版本校验、约 2.8 KB 载荷分片、校验值、乱序重组、ACK、重试和去重。
- `HotSeatTransport`、`LanRoomTransport`、`NearbyGameService`：分别承载本机热座、AES-256-GCM 局域网和星闪发现/可靠数据端口；附近连接入口当前隐藏。
- 房间页公开展示碰一碰与系统分享入口；Share Kit 发送 `tabletopparty://room` 一次性入局凭据，星闪扫描列表保持隐藏。
- 本地只保存昵称、设置、内容包和简要战绩；结束房间后释放私密对局状态，临时密钥不落盘。

## 发行前仍需完成的验收

当前交付是可构建、可热座游玩的功能基线，不应被标记为已经完成正式版全部验收。以下项目需要后续迭代或真实设备环境：

- 使用两台支持设备验证星闪发现、配对、双向动作、退出释放和重新加入；当前已实现发现、连接、可靠数据端口及局域网远程席位确认，但尚未把所有游戏动作和每席位私有快照完整接入多机对局页。
- 将局域网从单房间临时密钥升级为真正的逐连接密钥；当前 AES-GCM、随机 IV、AAD 与临时凭据已实现，但同一房间内仍共用本次房间密钥。
- 军棋增加玩家自定义合法布阵；当前采用双方独立、可复现的合法随机暗棋阵型。
- 四川麻将补齐碰、杠、一炮多响与固定番表结算；当前已具备 108 张、换三张、定缺、缺门约束、摸打、基础胡牌与血战继续。
- 掼蛋补齐逢人配、进贡还贡和连续牌局升级；当前已具备双副牌、搭档胜负、常用组合与炸弹比较。
- 你画我猜把本地 Canvas 笔迹点序列接入近场实时分片同步，并增加严格倒计时。
- 增加每款游戏的完整边界规则测试、UI 自动化、横竖屏专项截图测试和无星闪设备降级测试。

## 原创与商标边界

应用使用“彩牌对决”名称及原创四色规则表现，不包含 UNO 名称、Logo 或官方牌面。应用图标、启动图、大厅主视觉、12 张游戏详情封面、卡牌、棋子、麻将和棋盘主体均为原创或程序化绘制；少量对局类型图标来自 MIT 许可的 Tabler Icons，详见 `THIRD_PARTY_NOTICES.md`。
